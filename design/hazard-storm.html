Where "In storm" goes

The storm chip should always say Protected or Exposed, so the same fact is in the same place every turn. Whether the storm is sitting in this sector right now is a different fact, and it needs its own place. Each option is shown for a rock territory in the storm, a sand territory in the storm, and a territory the storm is not in, for comparison. The wording in the sentence variants is a placeholder.

Recommendation: B, the banner under the heading. It is the one fact in the popover that changes what you can do this turn, so it earns the loudest treatment, and a red strip is what the storm already looks like on the map. The chips below it then read the same in every popover. E is the quiet version if the banner is too much.
