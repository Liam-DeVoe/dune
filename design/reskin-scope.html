Scope check

Reskin, not redesign

Rule: every word, control, and position on screen stays where it is. Only materials, type, and the input widgets change. Below is what that rule includes and excludes, then seven real screens reskinned under it.

Will not change

  • Wording“Continue” stays “Continue”. “Please bid or pass.” stays. Tooltips, labels, headings, log sentences, error text: all verbatim.
  • Faction names beside sigilsNot added. Prompts and log lines keep bare sigils. This is the one I would argue for, but it adds words, so it is out.
  • Order and groupingPanels stay in their current order and stay open or closed as they are today. Advanced rules stay a flat list. Deals stay ungrouped. Sectors stay as separate rows.
  • New elementsNo countdown bar, no kicker line, no “who is next”, no toast notifications, no unread dots, no running totals, no quick-value buttons, no Decline or Counter, no Close on the combat wheels, no keep-me-signed-in.
  • BehaviourBid picker still does not re-sync. Continue automatically still defaults off. Chat still opens on edge hover. Icon-only buttons stay icon-only. Observe still crashes.
  • LayoutThree columns as they are. Map size as it is. Chat and users below the fold as they are. Phone stacks the desktop columns as it does now.

Judgement calls, and how I read them

  • Steppers to number inputsIn. You asked for this. Typeable, with the same range and default.
  • Logo font on player namesIn. The language says the wordmark font is for the wordmark only. The name is the same text in a different face.
  • Beige prompt to parchment act cardIn. Same box, same content, new material.
  • Faction-coloured panel backgroundsIn. The orange Fremen panel becomes ink. Faction colour lives in the sigil ring.
  • Two primary buttons side by sideKept. Where today has two blue buttons, tomorrow has two gold ones. Deciding which is primary is a UX call.
  • Red timerKept red, since it is red today. The bar under it is not added.
  • Popover contentVerbatim. Only the box, font, and colours change.
  • Blazor error barSame words, restyled.
