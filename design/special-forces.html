Special forces: ways to tell them apart

Today a special force only differs from a normal one by a small star in the art, which nearly disappears at map size. Each row below is one way to mark special forces more strongly. It's shown in the places forces appear: map stacks on sand, rock and a stronghold (the rock one at zoomed-out size), the player panel, the prompt card, the number input's icon cell, and the battle plan's token row. Every option is CSS over the existing token art. Special forces stay the same size as normal forces.

Faction

Things to weigh. On the map a stack is drawn as one image per force, offset up and to the left, so anything that draws outside the token's edge gets repeated down the stack. Rings and rims stay tidy. Rays, halos and the stacked coin get busy on a stack of 5. The stacked coin also reads as "two forces", which is true of Sardaukar strength but could be mistaken for a count. The octagon breaks the design language's rule that tokens are circles because they're round on the board. The star-in-count option only helps where a count is shown, so the token row and icon cell get nothing from it.
