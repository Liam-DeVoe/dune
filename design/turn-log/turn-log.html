Battles

The engine also starts a new report for each battle, so the panel shows only the current fight today. In all three layouts the battle phase keeps every fight, each under its own caption: who fought where, and the winner once the fight is decided. The fight in progress gets a gold rule. The engine already knows the aggressor, defender and territory when a battle starts, so the caption doesn't need new data.

What changes in the engine

A report is replaced in two places: Game.MainPhaseStart (Shared/Game.cs:287) and BattleInitiated.ExecuteConcreteEvent (Shared/Events/BattleInitiated.cs:219). Both would append the new Report to a list on Game instead of dropping the old one. A new turn would start a new list at the storm phase. That code already skips clearing on turn 1, so the setup log stays with turn 1. A battle report needs a caption, which BattleInitiated can set from its aggressor, defender and territory. ReportComponent then renders the list rather than Game.CurrentReport.
