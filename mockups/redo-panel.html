Mockups · host menu

Redo after an undo

After the host undoes some events, a panel offers to put them back. Today it reads Recently undone 2 event(s), lists two identical lines (Phase ended by Guild), and offers Restore or Dismiss. It doesn't say where the game now is, which phases the lines belong to, or that Dismiss throws the events away for good.

Every option below assumes one behaviour change: the redo offer disappears as soon as anyone plays a new event. Today it stays up, and Restore then silently wipes whatever was played since the undo. With that rule the offer only exists in the short gap right after an undo, which makes most of the wording problems smaller.

Today

A · Same panel, fixed wording

The smallest change. It reuses the undo panel's layout: Back to, then the undone events grouped by turn and phase. Redo is a secondary button, not green, because keeping the undo is the normal outcome. The close button replaces Dismiss.

B · The undo panel stays open

No separate panel. After the host confirms, the undo panel switches to a done state: the same list, struck through, and the Undo button turns into Redo. Closing the panel keeps the undo.

C · A toast instead of a panel

The familiar "Message deleted · Undo" pattern from mail apps, flipped around. A toast floats over the bottom of the map with one sentence and a Redo button. It disappears when anyone plays, or when the host closes it. The undone list isn't shown; the host just picked those events in the undo panel.

D · Redo on the timeline

The undo panel already uses a timeline under the map. After an undo, the undone stretch stays on that timeline as a dashed gold segment past the knob, with a Redo flag at its end. Clicking the flag redoes it. Hovering the segment lists the events, grouped as in the undo panel.

E · Redo button in the menu bar

Editor-style. A redo arrow sits next to the undo button, with a count badge, and lights up only while redo is possible. Clicking it opens a small popover that confirms what will come back.

For everyone else

Separately from which option the host sees: today the other players get no sign that an undo happened. One gold-ruled line in the log would fix that, whichever option is picked.
